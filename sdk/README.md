# Client SDKs

> **Version:** 2.3.0

Official client libraries for integrating with the ASR Feedback Intelligence Platform.

| SDK | Language | Status |
|---|---|---|
| [Python SDK](python/) | Python 3.9+ | Stable |
| [JavaScript SDK](javascript/) | Node.js 18+ / Browser | Stable |

## Quick Start

**Python:**
```bash
pip install asr-feedback-client
```

**JavaScript:**
```bash
npm install @asr-feedback/client
```
