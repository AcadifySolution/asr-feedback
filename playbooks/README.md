# Operational Playbooks

> **Version:** 2.3.0 | **Last Updated:** 2026-07-01

---

## Overview

Playbooks are step-by-step operational guides for core ASR Feedback processes. Every team member should be familiar with these playbooks and follow them consistently.

| Playbook | Purpose | Primary Audience |
|---|---|---|
| [Feedback Collection](feedback-collection.md) | How to collect structured 4-pillar feedback | Evaluators |
| [Quality Review](quality-review.md) | How to conduct quality audits | Quality leads |
| [Escalation Procedures](escalation-procedures.md) | When and how to escalate issues | All team members |
| [Model Comparison](model-comparison.md) | How to conduct A/B model evaluations | Evaluators, Engineers |
| [Continuous Improvement](continuous-improvement.md) | How to drive systematic quality improvement | Quality leads, Management |

---

## When to Use Playbooks

- **New team members:** Study all playbooks during onboarding
- **Experienced team members:** Reference when encountering unusual situations
- **Quality auditors:** Use as the standard against which to measure compliance
- **Process improvements:** Start with the existing playbook before proposing changes
